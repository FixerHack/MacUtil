# MacCleaner — план проєкту

Нативна програма для macOS: очищення, оптимізація, глибинний пошук, обслуговування системи й аналіз безпеки.
Аналог CleanMyMac + OnyX + інструментів Objective-See. Відкритий код на GitHub.

## Ухвалені рішення

| Питання | Рішення |
|---|---|
| Назва | **MacCleaner** |
| Для кого | Для себе + відкритий код на GitHub |
| Мова інтерфейсу | Українська та англійська |
| Версія macOS | Спершу **macOS 26 Tahoe** (дизайн Liquid Glass), пізніше підтримка старіших версій через `#available` |
| Підпис | Без платного акаунта Apple. Локально безкоштовний сертифікат Apple Development (стабільний підпис), для релізів на GitHub підпис ad-hoc |

## 1. Технології

- **Мова:** Swift 6 зі строгою перевіркою паралельності.
- **Інтерфейс:** SwiftUI, де потрібно — AppKit (вікна вибору файлів, рядок меню, перетягування).
- **Збірка:** Swift Package Manager + скрипт `scripts/build-app.sh`, який складає `.app`, додає `Info.plist`, ресурси та підписує.
- **Переклади:** поки немає Xcode — класичні файли `en.lproj/Localizable.strings` і `uk.lproj/Localizable.strings`. Після встановлення Xcode — перехід на String Catalog (`.xcstrings`).
- **Хешування:** CryptoKit (SHA-256 — він же потрібен для VirusTotal).
- **Схожі фото:** Vision.
- **Графіки:** Swift Charts + власне малювання карти диска.
- **Сховище:** налаштування та кеш результатів у `~/Library/Application Support/MacCleaner`, історія дій у SQLite.
- **Секрети:** ключ VirusTotal лише у Зв'язці ключів (Keychain), ніколи у файлах чи репозиторії.
- **Форматування коду:** SwiftFormat.

```
┌──────────── Програма MacCleaner.app (SwiftUI) ────────────┐
│ Головна панель │ Екрани модулів │ Монітор у рядку меню    │
└──────────────┬────────────────────────────────────────────┘
               │ асинхронні виклики, потік подій прогресу
┌──────────────▼──────────── Ядро (CleanerCore) ────────────┐
│ Сканер ФС        │ Рушій правил     │ Охоронець безпеки   │
│ Підрахунок місця │ Хешування        │ Перелік програм     │
│ Робота з Кошиком │ Журнал дій і скасування               │
│ Перевірка підпису│ Клієнт VirusTotal│ Запуск з правами root│
└──────┬─────────────────────────────────────────┬──────────┘
       │                                         │
┌──────▼──── Дії з правами адміністратора ─────┐ ┌▼─ Консольна ─┐
│ Етап 1: системний запит пароля (osascript)   │ │ утиліта mccli│
│ Етап 2: постійна служба-помічник через XPC   │ │ для тестів   │
└──────────────────────────────────────────────┘ └──────────────┘
```

Структура:
```
maccleaner/
  Package.swift
  Sources/
    CleanerCore/        # ядро: сканер, моделі, безпека, кошик, журнал
    SecurityCore/       # підписи, дозволи, налаштування безпеки, VirusTotal
    Modules/            # сміття, деінсталятор, дублікати, пошук, оптимізація...
    PrivilegedHelper/   # служба з правами root (пізніше)
    MacCleanerApp/      # інтерфейс
    mccli/              # консольна утиліта
  Resources/Rules/      # правила сміття у JSON
  Tests/
  scripts/build-app.sh
  .github/workflows/    # автоматична збірка й релізи
```

**Права адміністратора без платного акаунта.** Постійна служба-помічник надійно працює лише з підписом Developer ID. Тому на старті кожна дія з правами root виконується через стандартне системне вікно з запитом пароля. Помічника додамо пізніше як покращення.

## 3. Сканер файлової системи — тонкощі

- Швидкий обхід через `getattrlistbulk` / `fts`, паралельно по верхніх теках, зі скасуванням і прогресом.
- Рахуємо реальне зайняте місце на диску, а не номінальний розмір. Жорсткі посилання рахуються один раз.
- Клони APFS не показуємо як «звільнене місце».
- Файли iCloud, які не завантажені, не читаємо, щоб не запустити завантаження.
- Не рахуємо двічі `/System/Volumes/Data` і не переходимо на інші диски без дозволу.
- Перевіряємо повний доступ до диска. Якщо його немає, пояснюємо, як його надати.

## 4. Безпека програми

- За замовчуванням усе переміщується в Кошик. Остаточне видалення — окремий режим із підтвердженням.
- Жорсткий список заборонених шляхів: системні теки, зв'язки ключів, iCloud Drive, медіатека Фото, `.git`.
- Файли запущених програм не чіпаємо.
- Мовні пакети з програм не видаляємо, бо це ламає цифровий підпис.
- Журнал усіх дій, можливість скасування, режим пробного запуску.
- Файли без явної згоди нікуди не відправляються: у VirusTotal за замовчуванням іде лише хеш.

## 5. Модулі

### Очищення
1. **Розумне сканування.** Одна кнопка: сміття + Кошик + оптимізація + швидка перевірка безпеки.
2. **Системне сміття:** кеші, журнали, звіти про збої, пошкоджені налаштування, биті елементи автозапуску, стани вікон видалених програм, старі оновлення, вкладення Пошти. Резервні копії iPhone лише показуємо.
3. **Сміття розробника:** Xcode (проміжні збірки, архіви, підтримка пристроїв, симулятори); кеші npm, yarn, pnpm, pip, uv, Homebrew, CocoaPods, Gradle, Cargo, Go; Docker; старі `node_modules`.
4. **Кошики:** основний і на зовнішніх дисках.
5. **Приватність:** історія, cookies і кеш браузерів (коли браузер закритий), нещодавні документи, мініатюри.

### Місце на диску
6. **Карта диска** — інтерактивна діаграма з переходом у теки і видаленням.
7. **Великі та старі файли** — фільтри за розміром, датою, типом.
8. **Дублікати** — розмір → хеш початку і кінця → повний хеш. Враховує клони APFS. Пізніше схожі фото.

### Глибинний пошук
9. **Глибинний пошук:** назва, регулярні вирази, розмір, дати, тип, власник, приховані та системні файли. Швидкий режим через Spotlight і повний обхід диска. Пошук тексту всередині файлів. Необов'язковий власний індекс з автооновленням. Дії: показати у Finder, у Кошик, скопіювати шлях, швидкий перегляд, **перевірити у VirusTotal**.

### Програми
10. **Деінсталятор** з усіма слідами програми + скидання програми.
11. **Залишки видалених програм.**
12. **Оновлення програм:** Sparkle, Homebrew, Mac App Store.

### Оптимізація та обслуговування (як OnyX)
13. **Автозапуск:** усе, що стартує з системою, з розробником і підписом, вмикання/вимикання.
14. **Обслуговування:** DNS, оперативна пам'ять, Spotlight, база програм, кеші шрифтів/переглядів/іконок, знімки Time Machine, перевірка диска, права домашньої теки.
15. **Процеси:** навантаження на процесор і пам'ять, примусове завершення.
16. **Приховані налаштування:** приховані файли, скріншоти, Dock, `.DS_Store` на мережевих дисках тощо. Кожну зміну можна повернути.

### Моніторинг
17. **Монітор у рядку меню:** процесор, пам'ять, диск, мережа, батарея, сповіщення про нестачу місця.
18. **Планувальник:** сканування за розкладом.

### 19. Аналізатор безпеки (новий модуль)

Підсумок — **оцінка безпеки від 0 до 100** зі списком проблем. Для кожної проблеми вказано, чому вона важлива, і є кнопка «виправити» або інструкція. Звіт можна експортувати.

**19.1 Перевірка через VirusTotal**
- Спершу надсилаємо лише **SHA-256 хеш** файлу. Сам файл не відправляється, тож це приватно.
- Якщо VirusTotal файл не знає, файл можна завантажити на перевірку, але **лише за явною згодою**. Попередження: завантажені файли стають доступні дослідникам VirusTotal, тому особисті документи туди відправляти не можна.
- Безкоштовний ключ має ліміт: 4 запити на хвилину, 500 на день. Тому потрібна черга з обмеженням швидкості і локальний кеш результатів.
- Що перевіряти:
  - усі програми;
  - виконувані файли з автозапуску;
  - розширення ядра і системи;
  - нещодавні завантаження;
  - запущені процеси;
  - будь-який файл, перетягнутий у вікно.
- Кожен користувач відкритого проєкту вводить власний ключ, який зберігається у Зв'язці ключів.

**19.2 Підписи та цілісність програм**
- Чи підписана програма, ким (ідентифікатор розробника), чи пройшла нотаризацію Apple.
- Пошкоджений або змінений підпис: ознака, що програму підробили.
- Непідписані програми і програми з підписом ad-hoc.
- Hardened Runtime і небезпечні дозволи всередині програми (entitlements):
  - вимкнена перевірка бібліотек;
  - дозвіл на налагодження;
  - дозвіл на підміну бібліотек через змінні середовища.
- Карантинна позначка: звідки завантажено файл і чи перевіряв його Gatekeeper.

**19.3 Дозволи програм (конфіденційність)**
- Хто має доступ до камери, мікрофона, запису екрана, спеціальних можливостей, повного доступу до диска, моніторингу введення, автоматизації, геолокації, контактів і фото.
- Позначаємо підозрілі випадки: дозвіл у непідписаної програми, у вже видаленої програми, у програми, якою давно не користувалися.
- Кнопка скидання дозволу для конкретної програми.

**19.4 Системні налаштування безпеки**
- Захист цілісності системи (SIP).
- Gatekeeper.
- Шифрування диска FileVault.
- Брандмауер і режим невидимості.
- Версія та дата оновлення вбудованого антивірусу XProtect.
- Чи є незавершені оновлення macOS і чи увімкнено автооновлення.
- Автоматичний вхід без пароля, гостьовий акаунт.
- Запит пароля після сну або заставки.
- Віддалений вхід (SSH), віддалене керування, спільний доступ до екрана і файлів.
- Налаштування AirDrop.
- Режим блокування (Lockdown Mode).
- «Знайти Mac».

**19.5 Пошук закріплення в системі (як KnockKnock / BlockBlock)**
- Агенти і служби автозапуску.
- Елементи входу.
- Завдання cron.
- Розширення ядра і системи.
- Профілі конфігурації. Шкідливі профілі часто підміняють DNS або проксі.
- Розширення браузерів разом з їхніми дозволами.
- Підозрілі рядки у файлах оболонки: `.zshrc`, `.bash_profile`.
- Зміни у файлі `/etc/hosts`.
- Для кожного елемента: підпис, розробник, хеш і кнопка «перевірити у VirusTotal».

**19.6 Мережа**
- Які програми слухають мережеві порти.
- Активні вихідні з'єднання процесів.
- Налаштування DNS і проксі. Нестандартні значення — ознака перехоплення трафіку.
- Кореневі сертифікати, додані вручну. Через них можливе перехоплення HTTPS.

**19.7 Процеси та файли**
- Запущені процеси без підпису.
- Процеси, запущені з тимчасових або прихованих тек.
- Процеси, чий файл уже видалено з диска.
- Виконувані файли в теці Завантаження.
- Файли з правами SUID поза системними теками.
- Теки зі списку PATH, у які може записувати будь-хто.

**19.8 Особисті секрети**
- Права доступу до ключів у `~/.ssh` і вміст `authorized_keys`.
- Необов'язковий пошук відкритих токенів і паролів у файлах `.env` та конфігах у домашній теці. Лише показуємо, нічого не відправляємо.

## 6. Відкритий код на GitHub

- **Ліцензія:** MIT (проста) або GPL-3.0 (форки теж мають бути відкритими) — вирішити.
- **README** українською та англійською, скріншоти, інструкція зі збирання.
- **GitHub Actions:** автоматична збірка і тести на кожен коміт, реліз `.zip` за тегом.
- **Релізи без платного підпису:** користувачу потрібно дозволити запуск у «Системні параметри → Конфіденційність і безпека → Усе одно відкрити» або виконати `xattr -dr com.apple.quarantine MacCleaner.app`. Пізніше — власний Homebrew tap.
- **Жодних секретів у репозиторії:** ключі лише у Зв'язці ключів, `.gitignore` для збірок.

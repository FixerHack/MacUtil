# MacUtil

[English](README.md) · **Українська**

Безкоштовна програма з відкритим кодом для очищення, оптимізації та аналізу безпеки Mac.
Натхненна CleanMyMac, OnyX та інструментами Objective-See. Рідний Swift і SwiftUI, жодної телеметрії.

> **Стан:** рання розробка. План робіт у [PLAN.md](PLAN.md).

## Заплановані можливості

- **Очищення:** системне сміття, сміття розробника (Xcode, npm, pip, Homebrew, Docker…), Кошики, сліди приватності
- **Місце на диску:** карта диска, великі та старі файли, дублікати
- **Глибинний пошук:** за назвою, розміром, датою чи вмістом, включно з прихованими та системними файлами
- **Програми:** деінсталятор зі слідами, залишки видалених програм, оновлення
- **Аналізатор безпеки:** підписи й нотаризація, дозволи програм, системні налаштування безпеки,
  автозапуск, мережа, перевірка хешів через VirusTotal
- **Оптимізація:** автозапуск, обслуговування системи, процеси, приховані налаштування macOS

## Безпека

- Файли за замовчуванням переміщуються в Кошик. Нічого не видаляється назавжди без підтвердження.
- Захищені місця (системні теки, зв'язки ключів, iCloud Drive, медіатека Фото, `.git`) програма не чіпає.
- У VirusTotal надсилаються лише хеші файлів. Сам файл завантажується тільки на ваш явний запит.

## Вимоги

- macOS 26 Tahoe або новіша (підтримка старіших версій запланована)
- Swift 6: Xcode 26 або лише Command Line Tools

## Збирання

```bash
scripts/install.sh              # оптимізована збірка, встановлення в /Applications і запуск
scripts/build-app.sh            # налагоджувальна збірка → build/MacUtil.app
scripts/build-app.sh release    # оптимізована збірка
open build/MacUtil.app
```

Інші скрипти:

| Скрипт | Що робить |
|---|---|
| `scripts/test.sh` | Запускає тести (працює без Xcode) |
| `scripts/check-strings.sh` | Показує рядки інтерфейсу без українського перекладу |
| `scripts/snapshot.sh` | Зберігає знімок вікна програми (налагоджувальні збірки) |
| `swift run mucli` | Консольний інтерфейс до ядра |

### Повний доступ до диска

MacUtil потрібен повний доступ до диска, щоб бачити кеші, пошту та дані браузерів. Під час першого
запуску відкривається покроковий майстер: він відкриває потрібні налаштування, дозволяє перетягнути програму
в список і сам помічає, коли доступ надано. Запускайте копію з /Applications: дозволи прив'язані до програми
в цьому місці. Збірки з підписом ad-hoc після кожного перезбирання мають новий підпис, і macOS
забуває дозвіл. Якщо у вас є сертифікат «Apple Development» (безкоштовно з Apple ID у Xcode), скрипт
збирання підпише ним, і дозвіл зберігатиметься.

### Запуск завантаженої збірки

Релізи не нотаризовані. Після розпакування відкрийте Системні параметри → Конфіденційність і безпека
та натисніть **Усе одно відкрити**, або виконайте:

```bash
xattr -dr com.apple.quarantine MacUtil.app
```

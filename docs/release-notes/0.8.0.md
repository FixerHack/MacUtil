### What's new / Що нового

Seven ways to find space and order that nothing else was looking for.

Сім способів знайти місце й лад там, куди досі ніхто не заглядав.

**Keep folders tidy.** Rules file what lands in a folder: pictures to one place, installers to
another. A name pattern wins over an extension, because whoever wrote `Invoice*` meant something
more specific than "every PDF". Nothing moves until the whole plan has been shown, and a sort can
be undone in one press. A folder can also sort new arrivals by itself.

**Порядок у теках.** Правила розкладають те, що потрапляє в теку: зображення в одне місце,
інсталятори в інше. Правило за назвою перемагає правило за розширенням, бо той, хто написав
`Invoice*`, мав на увазі щось конкретніше за «всі PDF». Нічого не переміщується, доки ви не
побачите весь план, а розкладене можна повернути одним натиском. Тека також може розкладати нові
файли сама.

**Slim down apps.** A universal app carries a complete copy of itself for Apple Silicon and
another for Intel, and your Mac runs one of them. Removing the other frees gigabytes. Each app is
checked afterwards and put back untouched if its signature no longer holds.

**Зменшити програми.** Універсальна програма містить повну копію себе для Apple Silicon і ще одну
для Intel, а ваш Mac виконує одну з них. Вирізання другої звільняє гігабайти. Кожну програму після
зміни перевіряють і повертають недоторканою, якщо її підпис більше не тримається.

**Project build files.** Dependencies and build output live inside project folders, where no cache
cleaner looks — `node_modules`, `target`, `.venv`, `Pods` and the rest. One command brings any of
it back.

**Артефакти збірки.** Залежності й результати збірки лежать усередині проєктів, куди не заглядає
жоден чистильник кешів: `node_modules`, `target`, `.venv`, `Pods` та інше. Будь-що з цього повертає
одна команда.

**Installer files.** A disk image only carries an app to your Mac. MacUtil now checks whether the
app it carried ever arrived, and offers only those.

**Інсталятори.** Образ диска лише доставляє програму на ваш Mac. MacUtil тепер перевіряє, чи
програма справді дісталася, і пропонує прибрати тільки такі.

**History.** Everything MacUtil has ever removed or put back, grouped by day, with every path.

**Історія.** Усе, що MacUtil коли-небудь видалив чи повернув, по днях і з повними шляхами.

**Protected places.** The safety rules know what is dangerous to remove, not what you want to
keep. Anything on this list is left out of every scan.

**Захищені місця.** Правила безпеки знають, що небезпечно видаляти, але не знають, що вам потрібне.
Усе з цього списку не потрапляє в жодне сканування.

**Touch ID for sudo.** One line in `/etc/pam.d/sudo_local`, which system updates leave alone.

**Touch ID для sudo.** Один рядок у `/etc/pam.d/sudo_local`, який оновлення системи не чіпають.

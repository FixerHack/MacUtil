### What's new / Що нового

**Network adapters.** Every interface this Mac has, with its addresses, hardware address, link
speed and its own throughput — plus the order macOS tries them in and which one is carrying
traffic at this moment.

**Мережеві адаптери.** Усі інтерфейси цього Mac із адресами, апаратною адресою, швидкістю лінка
та власною швидкістю передавання — а також порядок, у якому macOS їх пробує, і позначка на тому,
що зараз несе трафік.

**Terminal.** Settings zsh, Git and ssh already document, described in words and switchable.
Everything MacUtil writes goes between two marked lines; the rest of your file is left exactly as
you wrote it, and turning a setting off takes its lines back out.

**Термінал.** Налаштування, які вже є в zsh, Git і ssh, — пояснені словами й з перемикачами. Усе,
що MacUtil записує, лежить між двома позначеними рядками; решта вашого файлу лишається точно
такою, як ви її написали, а вимкнення прибирає рядки назад.

**Clipboard history.** macOS keeps one thing; this keeps the last hundred, reachable from the menu
bar. Anything a password manager marks as concealed is skipped, and the list never leaves this Mac.

**Історія буфера обміну.** macOS тримає одне; тут зберігаються сто останніх, доступних просто з
рядка меню. Усе, що менеджер паролів позначає як приховане, пропускається, а список не залишає
цього Mac.

**System add-ons.** App extensions, the plug-in folders nothing else lists, software with no code
for this Mac, and files iCloud already holds — freeing those removes nothing, the file stays in the
Finder and downloads again when opened.

**Доповнення системи.** Розширення програм, теки плагінів, яких більше ніде не видно, програми без
коду для цього Mac і файли, що вже є в iCloud — звільнення місця нічого не видаляє, файл лишається
у Finder і завантажиться знову при відкритті.

**Removing software the way it was installed.** An app Homebrew installed is now removed by
Homebrew, optionally with the clean-up the cask itself describes. Installer receipts are read too:
macOS writes down every file a `.pkg` lays down, which is the one place an uninstall needs no
guessing. Every leftover now says why it was matched, not only the doubtful ones.

**Видалення так, як встановлювали.** Програму, яку поставив Homebrew, тепер знімає Homebrew — за
бажанням разом із прибиранням, описаним у самій касці. Читаються й квитанції інсталяторів: macOS
записує кожен файл, покладений пакетом `.pkg`, і це єдине місце, де нічого не треба вгадувати.
Кожен залишок тепер каже, на якій підставі його приписали програмі.

**Smaller things.** Project build folders can be kept out of Time Machine instead of removed.
Screenshots can be saved somewhere other than the Desktop, with the folder checked first.

**Дрібніше.** Теки збірки можна не видаляти, а виключити з Time Machine. Знімки екрана можна
зберігати не на робочий стіл, із перевіркою теки перед застосуванням.

### Fixed / Виправлено

- Reading a hardware address could walk off the end of the record for interfaces with longer names.
- Читання апаратної адреси могло вийти за межі запису для інтерфейсів із довшими назвами.

### What's new / Що нового

**What an app is built on.** The Uninstaller marks apps built on Electron (with its version), Tauri,
Flutter or Catalyst, and iPhone apps running on the Mac, and can show only those with the space they
take. An Electron too old to get Chromium's security fixes is now a finding in the Security Analyzer.

**На чому зроблено програму.** Деінсталятор позначає програми на Electron (з версією), Tauri, Flutter
чи Catalyst і програми iPhone, що працюють на Mac, і може показати лише їх разом із місцем, яке вони
займають. Electron, надто старий для виправлень безпеки Chromium, тепер — знахідка аналізатора безпеки.

**Vault.** Encrypted folders in a single file: an ordinary AES-256 disk image that opens with your
password, in UniMacHub or in Disk Utility on any Mac. It locks when the Mac sleeps, when the screen
locks, after a while without you, and when the drive it lives on is unplugged. The password can be
kept in the Keychain, and only there.

**Сейф.** Зашифровані теки в одному файлі: звичайний образ диска AES-256, що відкривається вашим
паролем — у UniMacHub або в Дисковій утиліті на будь-якому Mac. Блокується, коли Mac засинає, коли
блокується екран, після бездіяльності й коли від'єднано диск, на якому він лежить. Пароль можна
зберегти в Keychain, і лише там.

**DNS & Domains.** Cloudflare, Quad9, AdGuard or Google in one press, or back to automatic; encrypted
DNS over HTTPS as a profile you approve in System Settings; the DNS cache flushed. Development domains
point every name under, say, `.test` at this Mac, so a project runs at `app.test` instead of a port.
Temporary `/etc/hosts` entries come out by themselves when their time is up.

**DNS і домени.** Cloudflare, Quad9, AdGuard чи Google одним натиском або назад «автоматично»;
зашифрований DNS через HTTPS — профілем, який ви схвалюєте в Системних параметрах; очищення кешу DNS.
Домени для розробки спрямовують усе під, наприклад, `.test` на цей Mac, тож проєкт працює на
`app.test` замість номера порту. Тимчасові записи `/etc/hosts` прибираються самі, коли мине їхній час.

**Touch ID instead of the password.** With Touch ID for sudo on (System → Maintenance), UniMacHub's own
changes to the system take your fingerprint too; the password prompt stays as the fallback.

**Touch ID замість пароля.** Коли ввімкнено Touch ID для sudo (Система → Обслуговування), зміни системи
від UniMacHub теж приймають відбиток; вікно з паролем лишається запасним шляхом.

**Coming soon in the ring.** Dynamic Island, the assistant, Time Machine, iCloud sync, a file
converter, who is on the network and which apps connect where. The plan to 0.12 is in
[docs/ROADMAP.md](https://github.com/FixerHack/MacUtil/blob/main/docs/ROADMAP.md).

**Скоро в кільці.** Острівець, асистент, Time Machine, синхронізація iCloud, конвертер файлів, хто в
мережі й куди з'єднуються програми. План до 0.12 — у
[docs/ROADMAP.md](https://github.com/FixerHack/MacUtil/blob/main/docs/ROADMAP.md).

### Fixed / Виправлено

- UniMacHub's own entries in `/etc/hosts` are no longer reported as someone else's by the Security Analyzer.
- Власні записи UniMacHub в `/etc/hosts` аналізатор безпеки більше не показує як чужі.
- Tests that share the keep-awake switch no longer run side by side, and a disk image that hdiutil refuses once is tried again.
- Тести, що ділять перемикач «не засинати», більше не йдуть паралельно, а образ, який hdiutil раз відхилив, створюється повторно.
